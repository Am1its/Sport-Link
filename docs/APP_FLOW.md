# SportLink - App Flow & Core Features

**Phase:** Full Prototype Planning
**Target Audience:** Tel Aviv Amateur Athletes

## 📱 Core Application Screens (Bottom Navigation)
To provide a seamless user experience, the application is divided into 5 main tabs:

1. **🗺️ Map (Home):**
   * Visual discovery of nearby sports facilities using Google Maps.
   * Floating Action Button (FAB) to quickly create a new game.
   * Interactive markers with sport-specific icons (Basketball, Tennis, etc.).

2. **🔍 Discover:**
   * A detailed list view of upcoming games and available courts.
   * Advanced filtering: by distance, sport type, date, and required skill level.
   * *Future:* Sponsored local sports events (Marathons, Tournaments).

3. **📅 My Games:**
   * **Upcoming:** Games the user has joined or is hosting.
   * **Pending:** Invitations from friends or group members.
   * **History:** Past games played.

4. **💬 Chat & Community:**
   * Direct messaging with friends.
   * Group chats automatically created for specific game lobbies (e.g., "Thursday Basketball @ Sportek").

5. **👤 Profile:**
   * User details, preferred sports, and self-reported skill levels.
   * **Karma/Reliability Score** (see Unique Selling Propositions below).

---

## 🚀 Unique Selling Propositions (USPs) & "Startup" Features
Beyond basic scheduling, SportLink introduces features designed to solve real-world problems in amateur sports:

* **Karma / Reliability Score:** Users who attend games they committed to earn a high rating. "Ghosting" (canceling last minute) lowers the score. This ensures high-quality games.
* **Emergency Radar (The "Missing Player" Alert):** If a booked game is missing a player 2 hours before tip-off, the host can send a push notification to all relevant users within a 2km radius to fill the spot instantly.
* **Equipment Tags:** Game creators can specify missing equipment ("We have a court, need someone with a Size 5 Football").
* **Local Leaderboards:** Gamification rewarding the most active organizers in specific public parks (e.g., "The Mayor of Charles Clore Park").
